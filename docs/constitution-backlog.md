# 헌법 보류 항목

헌법(`.specify/memory/constitution.md`)에 아직 넣지 않은 후보.
"넣을 시점"이 오면 `/speckit-constitution`으로 개정한다.

| 항목 | 보류 이유 | 넣을 시점 |
|------|-----------|-----------|
| 언어 표준·타입 규칙 | 기술 스택 미정 | 첫 plan에서 스택 확정 후 |
| 정적 검사 도구명 (1.3 구체화) | 기술 스택 미정 | 첫 plan에서 스택 확정 후 |
| 관측성 (구조화 로그·메트릭) | 서버 구성 여부 미정 | 서버/백엔드가 spec에 들어올 때 |
| 성능 예산 (예: 지도 렌더링·GPS 지연) | 수치 근거 없음 | spec에 성능 요구가 생길 때 |
| 함수 복잡도 상한 | 현재 넣지 않기로 결정 | 재검토가 필요할 때 |
